# 🏠 Интеграционное тестирование HiTE PRO Gateway

Тесты REST API шлюза умного дома **HiTE PRO Gateway** на основе официальной спецификации [Спецификация API](https://cloud.mail.ru/public/k9he/nzDhMmiD6).

# 1. Ручное тестирование в Postman с автоматизацией на уровне запроса

## Описание Hite Pro Gateway API (Auto-ID)

Коллекция для работы с устройствами умного дома Hite Pro через Gateway API. Коллекция автоматически определяет ID устройств по их типам и позволяет управлять различными устройствами: датчиками движения, диммерами, RGBW-контроллерами и датчиками температуры.

## Базовый URL

```
{{baseUrl}}
```

Базовый URL задаётся через переменную окружения `baseUrl` в среде `Hite_Pro`.

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `baseUrl` | Базовый URL шлюза Hite Pro |
| `username` | Имя пользователя для авторизации |
| `password` | Пароль для авторизации |
| `switch_id` | ID выключателя |
| `dimmer_id` | ID диммера |
| `drive_id` | ID привода |
| `motion_id` | ID датчика движения |
| `illumination_id` | ID датчика освещённости |
| `temperature_id` | ID датчика температуры |
| `humidity_id` | ID датчика влажности |
| `checker_id` | ID контроллера |
| `water_id` | ID датчика воды |
| `power_id` | ID датчика мощности |
| `transmitter_id` | ID передатчика |
| `rgbw_id` | ID RGBW-контроллера |

## Запросы

### 0. Получить все устройства и определить ID по типам

**Метод:** `GET`

**URL:** `{{baseUrl}}/devices/`

**Описание:** Получает список всех устройств, подключённых к шлюзу. Используется для автоматического определения ID устройств по их типам.

![Отчет](docs/screenshots/report-0.png)
---

### 1. Проверить состояние датчика движения (если найден)

**Метод:** `GET`

**URL:** `{{baseUrl}}/devices/{{motion_id}}`

**Описание:** Возвращает текущее состояние датчика движения. Требует предварительного определения `motion_id`.

![Отчет](docs/screenshots/report-1.png)
---

### 2. Управление dimmer (если найден)

**Метод:** `PUT`

**URL:** `{{baseUrl}}/devices/{{dimmer_id}}/60`

**Описание:** Устанавливает уровень яркости диммера на 60%. Значение яркости указывается в URL (0-100).

![Отчет](docs/screenshots/report-2.png)
---

### 3. Управление RGBW (цвет, если найден)

**Метод:** `PUT`

**URL:** `{{baseUrl}}/devices/{{rgbw_id}}/100?color=00ff00`

**Описание:** Управляет RGBW-контроллером. Устанавливает яркость (100) и цвет (зелёный - `00ff00`) через параметр запроса.

**Параметры запроса:**

| Параметр | Значение | Описание |
|----------|----------|----------|
| `color` | `00ff00` | HEX-код цвета (RGB) |

![Отчет](docs/screenshots/report-3.png)
---

### 4. Проверить температуру (если найден датчик)

**Метод:** `GET`

**URL:** `{{baseUrl}}/devices/{{temperature_id}}`

**Описание:** Возвращает текущие показания датчика температуры.

![Отчет](docs/screenshots/report-4.png)
---

## Порядок выполнения

1. Выполнить запрос **"0. Получить все устройства"** для получения списка устройств и их ID
2. Сохранить полученные ID в соответствующие переменные окружения
3. Выполнять остальные запросы по мере необходимости

## Примечания

- Все запросы используют переменные окружения для ID устройств
- Перед использованием убедитесь, что среда `Hite_Pro` активна
- ID устройств определяются автоматически при первом запросе списка устройств
